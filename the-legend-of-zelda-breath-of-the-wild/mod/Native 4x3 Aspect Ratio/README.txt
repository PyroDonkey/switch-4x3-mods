Native 4x3 Aspect Ratio
The Legend of Zelda: Breath of the Wild, game version 1.6.0 only

Plays the game natively at 4:3 instead of stretching or letterboxing it. The
3D view renders at 4:3 and the HUD, menus and map are re-laid out for the
taller screen so nothing is squashed.

How to install, update and troubleshoot (please follow this guide):
https://github.com/PyroDonkey/switch-4x3-mods/blob/main/the-legend-of-zelda-breath-of-the-wild/README.md#install

Contents of this folder:
- exefs/1.6.0.pchtxt  aspect ratio 16:9 -> exactly 4:3
- romfs/Layout/*, romfs/Pack/*
                      the UI archives the mod changes; the rest come from the game

By PyroDonkey.

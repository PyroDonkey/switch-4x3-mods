Native 4x3 Aspect Ratio
Super Mario Bros. Wonder, game version 1.2.1 only

Plays the game natively at 4:3 instead of stretching or letterboxing it. The
camera, level framing and the whole UI are adjusted so nothing is squashed.

Full install guide, updating, troubleshooting, known limits and credits:
https://github.com/PyroDonkey/switch-4x3-mods/blob/main/super-mario-bros-wonder/README.md#install

QUICK INSTALL
Before you start: update the game to v1.2.1, turn off any other aspect-ratio
mod for this game, remove older versions of this mod, and close the game.
Windows: right-click the game > Configure Game > Add-Ons > Import Mod from ZIP,
  pick the zip, make sure "Native 4x3 Aspect Ratio" is ticked, then in the same
  window set Graphics > Aspect Ratio to Force 4:3.
Android: extract the zip, long-press the game > Add-ons > Install, select this
  "Native 4x3 Aspect Ratio" folder itself (the one containing exefs and romfs),
  make sure it is ticked, and set this game's aspect ratio to 4:3.
Other versions of the game are not supported and show a squashed 3D picture.

CONTENTS
- exefs/1.2.1.pchtxt  aspect ratio 16:9 -> 4:3 and camera fixes
- romfs/Layout/*      the UI screens the mod changes; the rest come from the game

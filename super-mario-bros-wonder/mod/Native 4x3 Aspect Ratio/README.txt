Native 4x3 Aspect Ratio
Super Mario Bros. Wonder, game version 1.2.1 only

Plays the game natively at 4:3 instead of stretching or letterboxing it. The
camera, level framing and the whole UI are adjusted so nothing is squashed.

How to install, update and troubleshoot (please follow this guide):
https://github.com/PyroDonkey/switch-4x3-mods/blob/main/super-mario-bros-wonder/README.md#install

Contents of this folder:
- exefs/1.2.1.pchtxt  aspect ratio 16:9 -> 4:3 and camera fixes
- romfs/Layout/*      the UI screens the mod changes; the rest come from the game

By PyroDonkey. Aspect-ratio address from the 32:9 Super Ultrawide mod (Stevens,
KeatonTheBot, Fl4sh_#9174; v1.2.1 port by KillswitchR6).
